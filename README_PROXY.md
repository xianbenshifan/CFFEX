# 东方财富答题代理服务使用说明

## 功能说明

这是一个HTTP代理服务器，可以：
1. **自动拦截**东方财富答题API的请求
2. **自动提取**题目内容
3. **自动搜题**并在题库中查找答案
4. **在控制台显示答案**，方便查看

## 安装依赖

```bash
pip install flask flask-cors requests
```

## 启动服务

```bash
python proxy_server.py
```

服务默认运行在 `http://0.0.0.0:8889`

可以通过环境变量修改配置：
- `PROXY_HOST`: 监听地址（默认: 0.0.0.0）
- `PROXY_PORT`: 监听端口（默认: 8889）

## 使用方法

### 方法一：使用HTTP代理（推荐）

1. **启动代理服务**
   ```bash
   python proxy_server.py
   ```

2. **配置设备代理**
   - 在手机/设备上设置HTTP代理
   - 代理地址：你的电脑IP地址（如 `192.168.1.100`）
   - 代理端口：`8889`
   - 注意：确保手机和电脑在同一局域网

3. **开始答题**
   - 打开东方财富APP进行答题
   - 代理服务会自动拦截题目请求并搜题
   - **答案会显示在控制台日志中**，方便查看

### 方法二：使用抓包工具转发

1. **使用Charles/Fiddler等抓包工具**
   - 配置抓包工具拦截 `quiz-activity.eastmoney.com` 的请求
   - 设置转发规则，将请求转发到 `http://localhost:8888`

2. **或者修改hosts文件**
   - 将 `quiz-activity.eastmoney.com` 指向本地
   - 但这种方法需要处理HTTPS证书问题

### 方法三：直接修改请求URL（适用于脚本）

如果你使用脚本发送请求，可以直接将URL改为代理服务器地址：

```python
import requests

# 原URL
# url = "https://quiz-activity.eastmoney.com/qa/api/quiz/Mzpvia"

# 改为代理URL
url = "http://localhost:8889/qa/api/quiz/Mzpvia"

response = requests.get(url, headers={...})
```

## 工作流程

1. **获取题目请求** (`GET /qa/api/quiz/<id>`)
   - 代理服务器拦截请求
   - 转发到真实服务器获取题目
   - 提取题目文本
   - 自动搜题找到答案
   - **在控制台显示答案信息**（题目、答案、相似度、选项索引）
   - 缓存答案（questionId -> 答案）
   - 返回原始响应（不修改，避免被检测）

2. **提交答案请求** (`POST /qa/api/quiz/answer`)
   - 代理服务器拦截请求
   - 检查缓存中是否有该题目的答案（仅用于日志显示）
   - 直接转发请求到真实服务器（不修改答案）
   - 返回响应

## API接口

### 1. 代理获取题目

**GET** `/qa/api/quiz/<quiz_id>`

自动拦截并处理获取题目请求。

### 2. 代理提交答案

**POST** `/qa/api/quiz/answer`

自动拦截并修改提交答案请求。

### 3. 查看缓存

**GET** `/cache`

查看当前缓存的题目和答案。

**响应示例：**
```json
{
  "count": 5,
  "cache": {
    "54263": {
      "question_text": "国债期货合约最后交易日之前的交割结算价...",
      "answer": "A",
      "similarity": 0.9462,
      "answer_index": 0,
      "all_results": [...]
    }
  }
}
```

### 4. 清空缓存

**POST** `/cache/clear`

清空所有缓存的题目。

### 5. 健康检查

**GET** `/health`

检查服务状态。

## 注意事项

1. **首次启动**：需要加载模型和向量，可能需要几分钟
2. **网络要求**：确保可以访问 `quiz-activity.eastmoney.com`
3. **HTTPS证书**：如果使用代理，可能需要安装证书（抓包工具通常提供）
4. **答案准确性**：答案基于语义相似度匹配，不保证100%正确
5. **缓存管理**：题目答案会缓存在内存中，重启服务会清空

## 故障排查

### 1. 无法连接代理

- 检查防火墙是否允许端口8889
- 确认手机和电脑在同一网络
- 检查代理地址是否正确

### 2. 搜题失败

- 检查模型和向量是否加载成功
- 查看日志中的错误信息
- 确认题库文件存在

### 3. 答案不正确

- 查看日志中的相似度分数
- 相似度低于0.7的结果可能不准确
- 可以手动检查 `/cache` 接口查看所有匹配结果
- **答案仅供参考，请根据实际情况判断**
